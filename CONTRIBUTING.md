# Guía de colaboración

## Flujo recomendado

1. Actualiza `main` antes de comenzar.
2. Crea una rama corta: `feature/nombre-tarea`, `docs/nombre-tarea` o `fix/nombre-error`.
3. Realiza commits pequeños y descriptivos.
4. Abre un Pull Request y explica qué cambió y cómo se verificó.
5. Pide revisión a otro integrante antes de fusionar cuando sea posible.

## Convención de commits

- `feat:` funcionalidad nueva.
- `fix:` corrección.
- `docs:` documentación.
- `test:` pruebas.
- `chore:` configuración o mantenimiento.

## Archivos que no deben subirse

No subir entornos virtuales, pesos de modelos, videos, resultados generados, contraseñas ni archivos `.env`. Para compartir videos, registrar en la bitácora su enlace, autor, licencia, duración y finalidad.
